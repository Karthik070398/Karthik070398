### 🔭 Featured Project

**[Streaming Data Platform](https://github.com/Karthik070398/streaming-data-platform)**
An end-to-end streaming platform modeling four real production challenges from
Netflix, LinkedIn, Uber, and Amazon's engineering blogs:
- Config-driven Kafka ingestion engine (source/sink connector pattern)
- Schema governance with Confluent Schema Registry + Avro enforcement
- Idempotent, offset-tracked consumers for exactly-once processing semantics
- Apache Flink windowed aggregation with event-time watermarking
- Prometheus + Grafana observability layer

Fully containerized with Docker Compose. See the repo's `PROGRESS.md` for a
detailed account of the infrastructure issues diagnosed and resolved along the way,
including a distributed watermark-stalling bug caused by a Kafka partition /
Flink parallelism mismatch.
